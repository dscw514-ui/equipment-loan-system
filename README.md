# V11：作業清單與續填功能

本版基於 V10。前端新增「已完成／進行中作業」下拉選單、重新整理、開啟查看、CSV 匯出；進行中的作業在同一瀏覽器工作階段持有編輯權杖時可繼續儲存與結束。

## 安裝
1. **先備份 Supabase 資料庫。** 在 SQL Editor 執行 `supabase/work-list-upgrade.sql`（增量 SQL，不要刪除原資料）。
2. 將 `js/app.js` 和 `js/backend.js` 覆蓋 GitHub 同名檔案。
3. 保留原本 `js/config.js` 設定；其他檔案無須更換。
4. 清除瀏覽器快取後，建立草稿→重新開啟→續填→儲存→結束→再次開啟並匯出 CSV。

## 權限與限制
- 所有網站訪客可查看最近 200 筆作業清單及作業詳細量測值；**這會改變先前僅管理者可查歷史的限制**。如涉及機密或個資，請勿啟用匿名查詢，應改為管理者登入或使用查詢碼。
- 作業編輯權杖只儲存在目前瀏覽器分頁的 `sessionStorage`。重整同一分頁通常可保留，關閉分頁、換裝置或清除工作階段後將無法以一般人員身份續填；管理者仍可在歷史紀錄編輯。
- 已完成作業不可由一般人員再修改；仍可查看及匯出 CSV。
- 網頁沒有自動儲存，切換作業前請先按「儲存作業」。
- 原本樣板 CSV 匯入／匯出、管理者歷史管理及 Mail 功能保留。
